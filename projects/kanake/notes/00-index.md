!!! summary "이 연구는"
    한국원자력연구원의 16관절 뱀로봇 **KAERI-SNAKE IV**(프로젝트 이름 Kanake)를 강화학습으로 제어한 기록이다. 석사 학위논문 *「심층 강화학습을 통한 뱀 로봇 주기적 이동 파라미터 최적화 제어」*(UST 인공지능 전공, 2026.02)의 내용을 실제 코드와 함께 정리했다. 핵심 아이디어는 **정책이 관절 각도를 직접 내지 않고, 정현파 보행의 관절별 진폭과 위상 방향만 고르게 한 것**이다. 탐색 공간이 작아져 학습이 안정적이고, 미분방정식이 없어 명령에 바로 반응한다.

![KAERI-SNAKE IV](assets/kaeri-snake.jpg)
*KAERI-SNAKE IV. Yaw·Pitch 관절이 번갈아 16개, 길이 760 mm.*

## 연구 흐름

| 단계 | 한 일 | 기록 |
|---|---|---|
| 1 | 사인파·CPG 보행 패턴을 ROS 2 노드로 만들고 실물에서 돌림 | [기록 1](01-ros-gaits.md) |
| 2 | 실물 사이드와인딩 실험 6세트 × 5회로 시뮬레이션 물리 파라미터 보정 | [기록 2](02-sim-calibration.md) |
| 3 | 강화학습 과제를 여러 번 바꾸며 액션 구조를 찾음 | [기록 3](03-rl-history.md) |
| 4 | 정현파 파라미터 액션으로 속도 명령 추종 학습 | [기록 4](04-rl-velocity.md) |
| 5 | 위치 추종 학습 + A* 전역 경로 + 웨이포인트 | [기록 5](05-rl-navigation.md) |
| 6 | U자형 통로 수동 조종, 미로 경로 추종 실험 (ATE 6.0–6.6 cm) | [기록 6](06-path-experiments.md) |
| 7 | 학습 정책을 ROS 2 노드로 옮겨 실물에서 실행 | [기록 7](07-policy-deploy.md) |

## 왜 정현파 파라미터를 학습하나

| 방식 | 장점 | 한계 |
|---|---|---|
| 해석적 모델 (serpenoid 곡선, 고정 파라미터) | 구조가 단순하고 예측 가능 | 지면·접촉이 바뀌면 사람이 다시 튜닝해야 함 |
| 관절 공간 강화학습 (관절 각도·토크 직접 출력) | 반응이 즉각적, 자유로운 동작 | 탐색 공간이 너무 커서 바퀴 없는 3차원 뱀로봇은 떨거나 파형이 무너짐 |
| CPG 기반 강화학습 (CPG 파라미터 출력) | 파형이 연속, 학습 효율 높음 | 미분방정식의 과도 응답 때문에 명령 반영이 한 박자 늦음 |
| **정현파 파라미터 강화학습 (이 연구)** | 파형 구조로 탐색 공간을 줄이고, 명시적 함수라 지연 없이 바로 바뀜 | 주파수를 고정하고 위상을 두 값으로 묶는 등 표현을 제한함 |

## 주요 결과

| 항목 | 결과 |
|---|---|
| 시뮬레이션 보정 | 실물 대비 최종 위치 평균 오차 Head 24.5 mm, Tail 48.9 mm |
| 학습 | 4096 환경 병렬, 10,000회, 약 5시간 (RTX 4070 Super) |
| 학습된 전략 | ±90° 안의 방향 전환은 **진폭 비대칭**으로 부드럽게, 역방향은 **위상 반전**으로 즉시 |
| U자형 통로 수동 조종 | 조이스틱 명령으로 2분 넘게 끊김 없이 주행 |
| 미로 경로 추종 | Target 1 평균 ATE 0.066 m (RMSE 0.077), Target 2 평균 ATE 0.060 m (RMSE 0.0685) |

## 로봇 사양

| 항목 | 사양 |
|---|---|
| 관절 | 16 DOF. Yaw(수평)·Pitch(수직) 관절 교차 배치. 코드에서는 `j1`~`j16`, 홀수 = 수직, 짝수 = 수평 |
| 크기 | 전체 길이 760 mm, 모듈 26 × 37.5 mm |
| 몸체 | `head`, `Link1`~`Link15`, `tail` (17개) |
| 센서 | 헤드 RGB 카메라 1, LED 조명 2 |
| 통신 | CAN 버스 |
| 전원 | DC 9 V, 꼬리 쪽 테더 케이블 |

## 사용한 알고리즘

| 분야 | 알고리즘 / 방법 | 쓰인 곳 | 기록 |
|---|---|---|---|
| 보행 | 사인파 관절 파동 (serpenoid) | 측면 굴림, 사이드와인딩, 직진, 슬리더링 | 1 |
| 보행 | CPG (위상 진동자 결합망) | 보행 전환, 강화학습 액션 시도 | 1, 3 |
| 시뮬레이션 | SDF 메시 충돌, 링크별 질량·마찰 보정 | 실물과 맞춘 시뮬레이터 | 2 |
| 강화학습 | PPO (RSL-RL), 정현파 파라미터 액션, 이산 위상 | 속도·위치 추종 정책 | 4, 5 |
| 강화학습 | 몸 전체 평균 속도 기반 리워드, 도메인 무작위화 | 흔들림에 강한 학습 신호 | 4 |
| 경로 계획 | A* (8방향), 안전 마진, 벽 거리 비용, RDP 단순화 | 미로 전역 경로 | 5 |
| 평가 | 절대 궤적 오차 (ATE), RMSE | 경로 추종 성능 | 6 |
| 실물 적용 | TorchScript / ONNX, 관측 재구성 | 정책 실행 노드 | 7 |
