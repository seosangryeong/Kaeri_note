!!! summary "이 프로젝트는"
    Teraffe는 원자력 시설의 높은 곳에 있는 밸브를 조작하기 위한 **4륜 이동형 고소작업로봇**이다. 네 다리(3단 텔레스코픽 리프트)의 길이를 따로 바꿔 높이(1.7–3.55 m)와 차체 수평을 조절하고, 상부에 로봇팔을 얹어 작업한다. **시뮬레이션**(Isaac Sim)에서는 주행, 자동 수평, 1 m 단차 넘기, 로봇팔로 밸브를 찾아 돌리는 작업까지 ROS 2로 만들었고, **실물**에서는 블록 체인 리프트의 모터와 엔코더를 직접 제어했고, 실물 밸브 조작을 위해 연구실 로봇팔(FR3)의 제어·카메라 보정·자동 작업 시퀀스를 만들었다. 다리 길이·조향·바퀴를 함께 쓰는 주행은 Isaac Lab과 MuJoCo에서 **강화학습**으로도 학습했다.

![Teraffe 통합 운용 시뮬레이션](assets/teraffe-integrated-sim.jpg)
*원자력 시설을 본뜬 장면에서 Teraffe가 Franka Panda를 얹고 고소 작업을 하는 통합 시뮬레이션.*

## 연구 배경

원자력 시설에는 높은 곳에 있는 밸브가 많다. 배관·구조물·단차가 얽혀 있고 냉각재 누출이나 방사선 오염 위험이 있어 사람이 직접 올라가기 어렵다. 기존 고소작업대는 크고 무거워 좁은 설비 사이로 들어가지 못하고, 안정성을 높이려면 아웃트리거 같은 장비와 설치 공간이 더 필요하다. 그래서 **작고 가벼우면서 높은 곳까지 안정적으로 올라가 밸브를 조작할 수 있는** 이동형 플랫폼을 만들었다.

![TeLoS와 그레이팅 바닥](assets/teraffe-telos.jpg)
*왼쪽: 기존 3륜 옴니휠 고소작업 로봇 TeLoS. 오른쪽: 원자력 시설의 그레이팅 바닥.*

기존 TeLoS를 실제 시설에 쓰려면 세 가지를 보완해야 했다. 단차와 그레이팅 바닥에서 옴니휠이 불안정했고, 위에서 작업할 때 플랫폼이 흔들렸으며, 밸브를 돌릴 때의 반력을 버틸 구조 안정성이 부족했다.

| 기존 TeLoS의 한계 | Teraffe에서 바꾼 것 |
|---|---|
| 3륜 옴니휠, 단차·그레이팅에서 불안정 | 4륜, 바퀴마다 독립 조향·구동, 서스펜션 |
| 상부 작업 중 흔들림 | 다리 4개를 따로 늘여 상부 플랫폼 수평 유지 |
| 밸브 조작 반력에 약함 | 3단 텔레스코픽 리프트, 다리를 벌려 넓은 지지면 |

## 하드웨어 설계

![하드웨어 설계](assets/teraffe-hw-design.png)
*왼쪽부터: 전체 구조, 리프트 상단의 블록 체인 하우징, 체인 블록.*

| 항목 | 값 |
|---|---|
| 총 질량 | 80 kg |
| 휠 모듈 질량 | 각 10 kg |
| 텔레스코픽 리프트 질량 | 각 10 kg |
| 리프트 구조 | 3단 텔레스코픽, 블록 체인으로 신축 |
| 높이 | 최소 1700 mm ~ 최대 3550 mm |
| 길이 × 너비 | 최소 높이 1000 × 780 mm, 최대 높이 2000 × 1380 mm |
| 구동 | 바퀴 모듈마다 독립 조향·구동 |

- 바퀴 모듈 4개가 각각 조향과 구동을 따로 한다.
- 텔레스코픽 리프트 4개로 상부 플랫폼을 올리고 내린다.
- 리프트를 따로 제어해 상부 플랫폼을 수평으로 유지한다.
- 리프트는 여러 블록을 이은 블록 체인을 밀어 늘인다(실물 1).

### 시뮬레이션 통합 모델

밸브 조작을 위해 플랫폼 위에 Franka Panda를 얹은 통합 모델을 Isaac Sim에 만들었다. URDF는 다리마다 직선 관절 2개(0–0.8 m)로 총 8개, 조향 관절 4개, 구동 관절 4개로 구성했다.

![통합 모델](assets/teraffe-integration.png)
*왼쪽부터: 4륜 고소작업 로봇, Franka Panda, 다리를 펴고 로봇팔을 얹은 통합 모델.*

## 발표

| 발표 | 내용 |
|---|---|
| 2026 춘계 원자력학회 | 「고소 위치 밸브 조작을 위한 4륜 이동형 고소작업 로봇 개발」 (서상령, 류정헌, 류동석, 신호철, KAERI Extreme Robot Lab) |
| KAERI 원자력로봇부 발표 (2026.10) | Light Weight Mobile Elevating Work Platform (MEWP): 메커니즘, 프로토타입, 시뮬레이션, 강화학습 |

## 두 갈래

| | 시뮬레이션 | 실물 |
|---|---|---|
| 패키지 | `teraffe_control_agent` | `teraffe_drive_control_agent` |
| 대상 | Isaac Sim 4.5 속 Teraffe + 지지팔 + Franka Panda | 실제 다리 리프트 4개, 실물 로봇팔 FR3 |
| 명령이 가는 곳 | `/joint_command` 토픽 하나 (JointState) | 모터에 CAN, RS-485로 직접 |
| 입력 | 조이스틱, GUI, 로컬 LLM, 카메라 | 웹 UI, 데스크톱 UI, ROS 토픽 |
| 기록 | 시뮬 1 ~ 5 | 실물 1 ~ 3 |

강화학습은 Isaac Lab에서 따로 했다. 정책이 다리 높이·조향·바퀴 속도를 직접 정해 거친 지형 위 목표 지점까지 가게 학습했다([강화학습 주행](09-rl-navigation.md)).

MuJoCo에서는 실제 로봇 URDF로 모델을 다시 만들어 조이스틱 제어기를 지형 위에서 다시 튜닝했고([MuJoCo 모델과 조이스틱 제어](10-mujoco-sim.md)), MuJoCo Warp로 GPU 병렬 강화학습을 했다([MuJoCo 강화학습](11-mujoco-rl.md)).

## 로봇 구조

| 부분 | 관절 | 하는 일 |
|---|---|---|
| 다리 4개 | 다리마다 직선 관절 2단 (`j1_1`, `j1_2` …) | 높이 조절. 1단이 다 늘어난 뒤 2단이 늘어남 |
| 조향 4개 | `j1_steer` ~ `j4_steer` | 바퀴 방향. 일반 조향, 게걸음, 제자리 회전 |
| 바퀴 4개 | `j1_drive` ~ `j4_drive` | 속도로 명령 |
| 지지팔 | `arm_pivot`, `arm_j1`, `arm_j2`, `arm_ext1`, `arm_ext2` | 좌우 회전, 관절 2개, 2단 신축 |
| 작업용 로봇팔 | Franka Panda 7축 + 그리퍼 | 밸브 돌리기 |

다리 번호는 1·3이 왼쪽, 2·4가 오른쪽이고 1·2가 앞이다. 다리를 줄였을 때 앞뒤 바퀴 간격(L)은 1.0 m, 좌우 간격(W)은 0.74 m로 계산했다.
