!!! summary "한 줄 요약"
    밸브를 돌리기 전 연습으로, 시뮬 속 Franka Panda 손끝이 세로 평면(YZ)에 원을 그리게 하는 일을 IK 방법 세 가지(MoveIt, roboticstoolbox, ikpy)로 각각 해 봤다. 그다음 목표 자세 하나로 가는 노드, GUI로 목표를 주는 노드, 조이스틱으로 손끝을 직접 미는 감쇠 최소제곱(DLS) 속도 제어 노드를 만들었다.

## 한 일

- 원 그리기를 IK 세 가지로 구현해 비교
- 목표 자세(위치 + 롤·피치·요) → IK → 부드러운 관절 궤적
- GUI에서 목표를 보내고 받는 노드
- 조이스틱 직교 좌표 제어: 손끝 속도 → 관절 속도
- 시뮬 관절 상태에서 Panda 관절만 걸러 다시 발행 (`/isaac_joint_states`)

시뮬로 가는 명령은 주행과 같이 `/joint_command`(JointState)에 Panda 7관절 + 손가락 2개 위치를 담아 보낸다.

## 원 그리기: IK 세 가지

| | MoveIt | roboticstoolbox | ikpy |
|---|---|---|---|
| 로봇 모델 | MoveIt 설정 (URDF/SRDF) | 내장 DH 모델 | Panda URDF에서 체인 생성 |
| 원 | 중심 (0.7, 0, 0.35), 반지름 15 cm, 220점 | 중심 (0.712, −0.01, 0.502), 반지름 8 cm, 180점 | 중심 (0.7, 0, 0.5), 반지름 8 cm, 한 바퀴 4초 |
| IK 방식 | 직교 경로 계획(`compute_cartesian_path`) 후 실행 | 점마다 `ik_LM` (Levenberg–Marquardt) | 점마다 `inverse_kinematics` |
| 자세 | 경로 계획이 처리 | 손 z축을 베이스 x축에 맞추고 손목 회전은 현재 값 유지 | 손 방향 전체 고정 |
| 안전 장치 | 경로의 95% 이상 풀려야 실행 | IK 실패 점은 건너뜀 | 관절 속도 제한, 저역 통과, 각도 감싸기, 2단계 진입 |

### 각 방법에서 한 것

- **MoveIt:** 원 위 점들을 웨이포인트로 주고 직교 경로를 받는다. 풀린 비율(`fraction`)이 기준보다 낮으면 실행하지 않는다. 실행은 `execute_trajectory` 액션.
- **roboticstoolbox:** DH 모델의 손끝(flange)과 시뮬의 `panda_hand` 프레임은 위치가 조금 다르다. 시작할 때 TF로 `World → panda_hand`를 읽어 두 프레임 사이 오프셋을 한 번 구해 두고, 목표를 손 기준으로 준 뒤 flange 기준으로 바꿔 IK를 푼다. 손목 회전(요)은 마스크로 빼서 풀기 쉽게 했다.
- **ikpy:** URDF에서 `panda_link0`부터 `panda_hand`까지 링크만 잘라 체인을 만들고, 7개 관절만 움직이게 했다. 매 주기 이전 해를 다음 IK의 시작값으로 쓴다.

ikpy 쪽은 관절이 튀지 않게 장치를 가장 많이 넣었다.

1. **2단계 진입:** 현재 위치 → 원 앞 안전 지점(YZ 평면에서 이동) → 원 시작점(X축으로만 직선 진입). 둘 다 코사인 곡선으로 가속·감속.
2. **각도 감싸기:** 새 해와 이전 해의 차이를 −π ~ π로 감싸서, 같은 자세인데 2π 다른 해로 한 바퀴 도는 것을 막는다.
3. **속도 제한:** 한 주기 관절 변화가 최대 속도를 넘으면 전체를 같은 비율로 줄인다.
4. **저역 통과:** 명령을 목표 쪽으로 일정 비율만 따라가게 한다.

## 목표 자세로 가기

목표 자세 노드는 목표 위치와 롤·피치·요를 받아 한 번 IK를 풀고, 현재 관절에서 목표 관절까지 `jtraj`(5차 다항식 보간)로 2초짜리 궤적을 만들어 0.02초마다 한 점씩 보낸다. 회전을 쓰지 않으면 IK 마스크를 `[1,1,1,0,0,0]`으로 두어 위치만 맞춘다. GUI 버전은 `/gui_target_pose`, `/gui_use_euler`, `/gui_gripper_cmd`로 목표와 그리퍼를 받는다.

## 조이스틱으로 손끝 밀기

| 입력 | 손끝 동작 |
|---|---|
| 버튼 2 / 3 | 앞 / 뒤 (최대 0.4 m/s) |
| 왼쪽 스틱 | 좌우·상하 (최대 0.8 m/s) |
| 오른쪽 스틱, 버튼 4·5 | 롤·피치, 요 (최대 1.0 rad/s) |
| 버튼 0 | 그리퍼 열기·닫기 토글 |

매 0.02초:

1. 스틱 값에 데드존(10%)을 적용하고, 0.25초 넘게 입력이 안 오면 멈춘다.
2. 회전 입력이 없으면 저장해 둔 목표 방향과의 오차로 **방향 유지 보정**을 만든다(게인 4, 최대 1 rad/s). 손끝을 밀어도 손 방향이 틀어지지 않는다.
3. 자코비안으로 손끝 속도를 관절 속도로 바꾼다(감쇠 최소제곱).
4. 관절 속도를 2.3 rad/s, 가속을 8 rad/s²로 자른다.
5. 새 관절 명령이 실제 관절에서 0.15 rad 이상 벌어지지 않게 하고, 관절 한계로 자른다.

## 설계에서 신경 쓴 점

- **DH 모델 손끝 ≠ 시뮬 손:** roboticstoolbox 내장 DH 모델의 끝점(flange)과 시뮬 USD의 `panda_hand` 프레임은 같은 점이 아니다. 시작할 때 TF와 순기구학으로 두 프레임 사이 변환을 한 번 재서, 목표를 손 기준 → flange 기준으로 바꿔 IK에 넣는다.
- **특이점 근처 감쇠:** 팔을 쭉 펴거나 손목이 일직선이 되는 자세 근처에서는 자코비안 역행렬이 아주 큰 값을 낸다. 가장 작은 특이값이 0.1보다 작아지면 감쇠를 0.05에서 최대 0.25까지 키워, 정확도를 조금 내주고 관절 속도가 터지는 것을 막는다.
- **명령과 실제의 간격 제한:** 시뮬 관절이 명령을 못 따라가는 동안 명령만 앞서 나가지 않게, 명령을 실제 관절 ±0.15 rad 안으로 묶는다.

## 원리

??? 수치 IK (Levenberg–Marquardt)
    목표 자세 T와 현재 관절 q의 손끝 자세 사이 오차 e를 줄이는 q를 반복해서 찾는다.

    `Δq = (JᵀJ + λI)⁻¹ Jᵀ e`

    λ가 작으면 가우스–뉴턴처럼 빠르게, 크면 경사 하강처럼 조심스럽게 움직인다. 오차가 줄면 λ를 줄이고 늘면 키운다. 7축 Panda는 해가 여러 개라 **시작값(q0)**에 따라 다른 해가 나온다. 그래서 연속 궤적에서는 이전 해를 다음 시작값으로 쓴다.

    마스크 `[1,1,1,1,1,0]`처럼 자유도 일부를 빼면 그 방향 오차는 신경 쓰지 않아 해 찾기가 쉬워진다.

??? 감쇠 최소제곱(DLS)과 적응 감쇠
    손끝 속도 v(6차원)를 관절 속도로 바꿀 때 그냥 의사역행렬을 쓰면 특이점에서 터진다. 감쇠를 넣으면

    `q̇ = Jᵀ (J Jᵀ + λ² I)⁻¹ v`

    λ가 클수록 큰 관절 속도에 벌점을 줘서 안전하지만, 원하는 손끝 속도를 덜 정확히 따른다. 그래서 평소엔 작은 λ(0.05)를 쓰고, 자코비안의 최소 특이값 σ_min이 기준(0.1)보다 작아질 때만

    `λ = λ₀ + (λ_max − λ₀) · (1 − σ_min / 기준)²`

    으로 키운다. σ_min은 "가장 움직이기 어려운 방향으로 얼마나 움직일 수 있나"를 뜻한다.

??? 방향 유지 오차
    현재 회전 R과 목표 회전 R*의 오차를 각속도로 바꾸는 간단한 식이다.

    `e = ½ (r₁ × r₁* + r₂ × r₂* + r₃ × r₃*)` (rᵢ: 각 회전 행렬의 i번째 열)

    작은 각도에서는 회전축 × 각도와 같아진다. 여기에 게인을 곱해 각속도 명령으로 쓰면 손 방향이 목표로 돌아온다.
