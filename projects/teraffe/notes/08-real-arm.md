!!! summary "한 줄 요약"
    Teraffe 위 로봇팔로 **실물 밸브를 돌리기** 위해, 연구실의 Franka Research 3(FR3)를 ROS 2로 직접 제어하는 기반을 만들었다. 제어 스택, 경로 계획, 카메라 보정까지 갖춘 뒤, 목표물(40 mm 큐브)을 **보고 → 다가가 → 작업하고 → 다시 보고 확인하는** 흐름을 사람 손 없이 132회 반복해 96회 성공했다. 다음은 [시뮬 5](05-sim-valve.md)의 밸브 인식과 원 궤적을 이 구성에 붙여 실물 밸브를 돌리는 것이다.

## 한 일

| 단계 | 내용 |
|---|---|
| 제어 스택 | franka_ros2 빌드, 실시간 커널 설정, 팔 컨트롤러를 필요할 때만 켜는 순서 |
| 모션 | MoveIt 경로 계획(OMPL), 목표 근처에서는 직선 경로, 그리퍼, 실제와 같은 테이블 충돌 모델 |
| 카메라 보정 | 손목 RGB-D 카메라(RealSense D435i)의 hand-eye 보정: 20자세, 방법 5가지 비교, 오차 7.0 mm |
| 목표 인식 | 깊이에서 평면을 맞춰 목표의 위치·크기·회전각을 구하고, 크기와 기울기로 다른 물체를 걸러냄 |
| 자동 시퀀스 | HOME에서 찾기 → 위로 이동 → 바로 위에서 다시 보기 → 직선 하강·작업 → 복귀 후 다시 보고 성공 판정 |

카메라가 본 픽셀을 로봇이 갈 목표로 바꾸는 과정은 **픽셀 + 깊이 → 카메라 좌표 → 손목(hand-eye 보정값) → 로봇 베이스(관절값으로 계산)**다. 밸브도 같은 체인으로 시뮬 5에서 구한 밸브 면의 중심과 법선을 로봇 좌표로 옮기면 된다.

## 밸브 조작으로 이어지는 점

| FR3에서 확인한 것 | 밸브 조작에서 쓰는 곳 |
|---|---|
| 손목 카메라 → 로봇 좌표 변환 (hand-eye) | 밸브 중심·법선을 로봇 좌표로 옮기기 |
| 목표 바로 위에서 한 번 더 보고 다가가기 | 밸브 정면에서 다시 보고 손잡이 위치 보정 |
| 목표 근처는 직선 경로로만 움직이기 | 밸브에 정렬한 뒤 손잡이로 곧게 접근 |
| 작업 후 다시 보고 성공 판정 | 밸브가 실제로 돌았는지 확인 |

## 트러블슈팅

!!! issue "실물 충돌"
    **문제** 시험 중 손목이 테이블 위 알루미늄 레일에 닿아 비상정지했다.

    **원인** 충돌 모델에 레일이 없었고, 로봇 베이스 위치도 실제와 16 cm 어긋나 있었다.

    **해결** 실물을 재서 테이블과 레일을 충돌 모델에 넣고 베이스 위치를 바로잡았다. 모든 이동은 계획을 먼저 확인한 뒤 실행하게 했다.

!!! issue "잡는 위치가 늘 한쪽으로 밀림"
    **문제** 목표의 중심보다 늘 로봇 쪽을 잡았다.

    **원인** 비스듬히 본 깊이에서 카메라 먼 쪽 가장자리가 빠져, 찾은 중심이 로봇 쪽으로 밀렸다.

    **해결** 목표 바로 위로 먼저 이동해 한 번 더 보고 내려가게 했다. 밸브처럼 정확한 위치가 필요한 작업에서도 같은 방식을 쓴다.
