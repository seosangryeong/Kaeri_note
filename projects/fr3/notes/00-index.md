!!! summary "이 프로젝트는"
    연구실에서 로봇팔을 따로 개발하고 있어, 그 제어와 작업 설계에 참고하려고 **Franka Research 3 로봇팔을 ROS 2로 직접 제어한** 기록이다. 제어 스택 구축부터 MoveIt 경로 계획, 그리퍼, 테이블 충돌 모델, 카메라 보정(내부·외부·hand-eye)을 거쳐, 손목 RGB-D 카메라로 큐브를 찾아 집고 반대편 트레이에 놓은 뒤 **다시 보고 성공을 확인하는 자동 시퀀스**를 만들었다. 이 시퀀스를 사람 손 없이 132회 반복해 돌렸다. 모은 데이터로 모방학습도 시험하고 있다.

## 지금 상태

| 상태 | 내용 |
|---|---|
| 완료 | ROS 2 제어 스택 구축: franka_ros2 빌드, 실시간 커널 설정, 컨트롤러 켜고 끄기 순서 |
| 완료 | 모션 API: MoveIt 경로 계획, 직선 하강, 그리퍼, TCP ↔ link8 변환, 테이블 충돌 모델 |
| 완료 | 카메라 보정: 고정 카메라 내부·외부 보정(solvePnP), 손목 카메라 hand-eye 보정 |
| 완료 | 깊이로 큐브 윗면 검출: 위치, 크기, 회전각, 옆면 걸러내기 |
| 완료 | 자동 이송 시퀀스: 132회 무인 반복, 96회 성공 |
| 진행 중 | 모방학습(BC·ACT) 시험 |

## 핵심 구현

### 좌표 변환 체인

카메라가 본 픽셀을 그리퍼가 갈 목표로 바꾸는 과정이다.

| 단계 | 변환 | 구한 방법 |
|---|---|---|
| 픽셀 + 깊이 → 카메라 좌표 | 핀홀 모델 | 카메라 내부 파라미터 |
| 카메라 → 손목(link8) | `link8_T_camera` | hand-eye 보정 (20자세, 방법 5가지 비교, LOO 7.0 mm) |
| 손목 → 로봇 베이스 | `base_T_link8` | 매 순간 관절값으로 계산 (TF) |
| 그리퍼 끝(TCP) ↔ link8 | 10.34 cm 오프셋 | 목표는 TCP로 받고, IK 직전에 link8로 변환 |

보정 오차가 가장 큰 높이(Z)는 보정값 대신 직접 잰 트레이 높이와 큐브 크기로 정했다.

### 충돌 모델과 안전 장치

- 실물 충돌(손목이 테이블 레일에 닿아 비상정지) 후, 로봇 메시를 직접 재서 **실제와 같은 테이블 충돌 모델**을 넣었다. 베이스 위치도 16 cm 어긋나 있던 것을 바로잡았다.
- 목표점은 테이블 위 3 cm 여유를 따로 검사한다.
- 팔 컨트롤러는 평소에 꺼 두고 움직일 때만 켠다. 모든 이동은 계획을 먼저 보여 주고 `--execute`를 붙여야 실행된다.
- 큐브 쪽으로 내려가고 올라오는 구간은 직선 경로로 움직이고, 경로가 99.9% 미만으로 만들어지면 실행하지 않는다.

### 실패 대응 로직

- 비스듬히 본 깊이 때문에 잡는 위치가 밀리는 문제를 **큐브 바로 위에서 한 번 더 보고** 내려가는 방식으로 해결했다.
- 다시 보기에서 못 찾으면 8초 뒤 처음 검출값으로 진행해, 시퀀스가 멈추지 않게 했다.
- 놓은 뒤 HOME에서 다시 검출해 **목표에서 25 mm 이내면 성공**으로 판정한다.
- 크기(40 mm 정사각형)와 면 기울기(수평 20° 이내)로 큐브 옆면이나 다른 물체를 걸러낸다.

## 작업 흐름

손목 카메라 RGB-D → 큐브 윗면 검출 → 로봇 좌표로 변환 → 큐브 위로 이동(OMPL) → 위에서 다시 보기 → 직선 하강·잡기 → 반대편 트레이로 이동 → 직선 하강·놓기 → HOME에서 다시 보고 성공 판정 → 반대 방향으로 반복

## 사용한 알고리즘

각 기록 안에 **원리** 칸을 펼치면 설명이 있다.

| 분야 | 알고리즘 / 방법 | 쓰인 곳 | 설명 있는 기록 |
|---|---|---|---|
| 제어 | IK, OMPL, Cartesian path | 목표 자세까지 경로, 큐브 쪽 직선 하강 | 2 |
| 비전 | 카메라 내부 보정, solvePnP, 광선–평면 교차 | 고정 카메라 픽셀 → 로봇 좌표 | 보정 정리, 3 |
| 비전 | Hand-eye 보정 (AX = XB) | 손목 카메라 ↔ 손목 변환 | 보정 정리 |
| 비전 | 깊이 평면 맞추기(SVD), 최소 면적 사각형 | 큐브 윗면 위치·크기·회전각 | 4 |
| 학습 | BC, ACT | 자동 시퀀스 데이터로 시험 중 | 6 |
