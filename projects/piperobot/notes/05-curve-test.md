!!! summary "한 줄 요약"
    배관 목업의 수평 곡관에서 직선 주행 → 곡관 진입 → 곡관 주행 → 통과를 시험했다. 기울기 센서 제어로 모듈이 배관 꼭대기에서 지면과 평행을 유지했고, 앞뒤 모듈 간 거리도 일정하게 지켜 곡관을 통과했다. 바퀴를 캐스터형과 구동 모터형으로 바꿔도 똑같이 통과했다. 기존 로봇이 못 하던 수평 곡관 주행이라는 과제 목표를 달성했다.

## 한 일

- 수평 직선 구간 주행
- 수평 곡관 통과 (엘보 곡률 반경 457 mm)
- 바퀴 구조 3종 비교

## 실험 구성

| 항목 | 내용 |
|---|---|
| 목업 | 외경 318.4 mm, 엘보 곡률 반경 457 mm, 수평 곡관 |
| 로봇 | 앞뒤 구동 모듈 2개, JS-R8 8개, SINDT-485 2개 |
| 제어 | Roll PD + Yaw 차이 보정 ([기울기 센서 자세 제어](04-tilt-control.md)) |
| 조종 | ROG Ally X GUI, Wi-Fi TCP/IP |

## 곡관 통과

![곡관 통과 실험](assets/pipe-experiment.jpg)
*왼쪽부터: 직선 주행, 곡관 진입, 곡관 주행, 곡관 통과.*

| 단계 | 결과 |
|---|---|
| 직선 주행 | 안정적으로 주행. 앞뒤 Yaw가 같아 Yaw 보정은 0에 가깝고 Roll 보정만 동작 |
| 곡관 진입 | 앞 모듈이 먼저 꺾여 Yaw 차이 발생 → 바깥쪽 바퀴 가속 |
| 곡관 주행 | 두 모듈 모두 배관 꼭대기에서 지면과 평행 유지, 모듈 간 거리 일정 |
| 곡관 통과 | 뒤 모듈이 빠져나오며 Yaw 차이가 줄어 직선 주행으로 복귀 |

## 바퀴 구조 비교

![바퀴 구조 3종](assets/pipe-wheel-types.png)
*왼쪽부터: 고마찰 수동 바퀴, 캐스터형 바퀴, 모터 일체형 구동 바퀴.*

날개 끝의 바퀴는 환경에 따라 바꿔 끼울 수 있게 했다.

| 바퀴 | 장점 | 맞는 환경 |
|---|---|---|
| 고마찰 수동 바퀴 | 마찰이 커서 덜 미끄러짐 | 표면이 미끄럽고 경로가 단순한 직선 위주 |
| 캐스터 / 롤러 | 방향 바꿀 때 마찰 저항이 작음 | 곡선·분기가 많아 방향 전환이 잦은 곳 |
| 모터 일체형 구동 바퀴 | 추진력 추가 | 센서·배터리로 무거워졌거나 수직 등반처럼 힘이 더 필요할 때 |

캐스터형과 구동 모터형으로 바꿔 시험한 경우에도 로봇은 자세를 유지하며 곡관을 지났다.

!!! lesson "배운 점"
    - 앞뒤 두 모듈 + 좌우 독립 바퀴 + 기울기 피드백만으로, 관절을 늘리지 않고도 수평 곡관을 지날 수 있었다.
    - 날개 끝 바퀴를 교체형으로 두니 같은 몸체로 여러 환경을 시험할 수 있었다.

## 남은 점

- 정량 기록(주행 속도, Roll 오차, 모듈 간 거리 변화)을 남기지 못했다. 다음 실험에서는 GUI에 들어오는 Roll·모터 값을 저장한다.
- 수직 배관 등반, T자 분기관, 실제 보온재 표면 시험은 아직이다.
